# Den's Fantasy World

Apart of the Modding Jam. All commits are due by 31st May, at 12:00 (12pm) EST.

Rules: <br>
<ol>
  <li>All tags must begin with Z</li>
  <li>Every file for your nation(s) must start with their TAG</li>
  <li>All OP content will be removed</li>
  <li>Any files that cause many errors will be removed</li>
  <li>No teams</li>
  <li>Provinces and states in your territory <b>can</b> be modified, you can put multiple countries in your territory</li>
  <li>Maximum 20 states for claimed land</li>
</ol>

What can be included: <br>
<ol>
  <li>Your lore can include whatever you want</li>
  <li>All technology has to be standard 1936 tech</li>
  <li>Any races/species/creature can be added, but it must be cosmetic only</li>
  <li>Any changes to tech/unit types must be approved by a moderator before being added</li>
</ol>
